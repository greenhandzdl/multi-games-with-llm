# 多智能体博弈数据引擎（狼人杀）

九个 LLM 座位自己打一局中文狼人杀：引擎判定一切合法动作、把每个决策落成一条 append-only JSONL 事件，然后离线复盘给其他人看。产品形态是数据引擎，不是聊天机器人——日志是唯一真相源，指标和界面都只是它的纯函数，所以端点明天被重启、换权重、下线，演示照样能跑。引擎拥有真值（发牌、合法性、结算、胜负），模型只拥有语言（发言文本、它自报的怀疑排序）；这条分工决定了本仓库几乎所有代码的形状。全部命令、离线演示与真人上桌的配方在 [docs/cli.md](docs/cli.md)，指标口径在 [docs/metrics.md](docs/metrics.md)，统计协议在 [docs/comparison.md](docs/comparison.md)，视图与颜色在 [docs/views.md](docs/views.md)，延迟常数只住 [docs/calibration.md](docs/calibration.md)。手册里那些 `#NNN` 形的号是任务清单的编号，那本清单不随仓库发布，仓库内唯一的落点是 `docs/iterations.md`——要复核就按号检索，别把它当成点得开的链接。那些「具数见某节」式的节名指针也同理：它们大半住在 `docs/iterations.md` 里，不在手册的任何一页上——要复核就按节名在那一本里检索。

## 安装与配置：密钥的值永远不进文件

```bash
uv sync --extra dev          # 或 pip install -e ".[dev]"；需要 Python ≥ 3.12
export WOLF_LLM_API_KEY=<key>      # 只在 shell 里，值不进文件
uv run wolf --help                 # 列出子命令：每一枚旋钮的自述只住在 `wolf <子命令> --help` 里
uv run wolf run --games 1 --mock --seed 7 --out /tmp/wolf-demo    # 全程不发请求
```

端点与模型**不走环境变量**：它们非密，以字面量躺在 `config.py` 的字段默认值里，并且同坐 `FORBIDDEN_AXIS` 那张名单——换掉它们等于换了端点，所以 `compare` 与 `--set` 都拒绝把它们声明成处理轴。`.env.example` 只许列真有人读的名字，这件事和「提交历史里有没有混进过 key」都由 `tests/test_no_secrets.py` 数着；写盘的 `request` / `response` 走白名单，`headers` 连键名都不落盘。
## 这个仓库现在能做什么、不能做什么
- ✅ 一句主张怎么核对：判词写成 `CAUGHT [hang after Ns]` 并记下最后一行开始跑的测试文件名，光杆的判词不算判决；那具会先 `backup()` 的刀讲的是 harness 自己的动作，不是引擎的函数。
- ✅ 一局自玩到给人看的出口：判定链（夜间能力、用药、验人、放逐、遗言、猎人开枪、胜负、日数上限的预注册平局）、离线复盘、直播、上帝视角、八组指标；`run --mock` → `replay` → `export` → `watch --once` 全程不发请求。
- ✅ 胜负判据只认阵营键空间：参数名、注解、docstring、"不许存在按职业建键的孪生"、`check_win` 喂的是哪一手，五件事一起钉在一条守卫上（`#80`，八具变异见〈胜负判据的参数名叫 `alive_roles`…〉）；法官嘴上那句"结论"与它下一步真的做过的事是同一个谓词说了算（`#87`，八具手术刀全部具名兑现）。
- ✅ 「要有读者」那把尺逐层加宽：函数（`#81`，六具变异）、类（`#85`：六具变异里三具是负控制）、入参（十四具变异见〈签名要求你递、函数体从不看的入参…〉）、导入（`#83` 引擎侧七具变异、`#84` 测试侧四具变异），方法、字段、常量、文件、局部名各有一层判据，认的是"引用次数为零"这个形状而不是任何一份清单。
- ✅ 读不下去的日志说的是人话：末行撕裂、拿错文件种类、空文件、编号破损四形各一句，带文件名、行号与缺哪些键，到终端是一行报告加退出码 2 而不是 traceback（判据与九批电池各批的具数见〈日志读不下去的时候：砍断的末行与拿错的文件〉；批次侧 8 具变异见〈编号破损走进了批次目录〉，9 具变异见〈同一份被砍的日志，批次报告以前说"这局没打完"〉）。
- ✅ 端点拒答伪装不成模型行为：非 200 里只有"答案取决于你什么时候问"的那两类（408/429）和一条压缩令按轮处理，其余连一局都不留（7 具变异见〈端点说不的时候，谁替九个座位答的话〉一节）；一局打完的退出码来自判据、不来自收尾崩溃（6 具变异见〈一局打完了、退出码却是 1：收尾时在第二个 event loop 里关 client〉）。
- ✅ 什么都不产的命令不再冒充结论：`--games` 少于 1 局由 `run` 与 `batch` 各自在建目录、写 manifest 之前拒掉（7 具变异见〈零局的批次先落了盘，再在摘要行上读一个空列表〉）；`--seat` 越界、`--set` 要一块代码里不存在的板子也在读文件之前拒（10 具变异见〈类型过了、范围没过：越界的 --seat 印出一份观众视图，要一块不存在的板子留下一个空目录〉）。
- ✅ 墙钟乘数是量出来的：`--dry-run` 末尾印每局调用次数与 prompt token，一局真跑完之后 `m7_cost` 还报兑现率，发请求的人和普查的人读同一个计价函数；未知的那半只有 `docs/calibration.md` 的两格吞吐常数。
- ✅ 文档里每一个号都可核对：用例名与条数、收集数、行号与摆放理由、出厂值、节标题指针、具数落点各有闸门；`phases.py` 里那串"这里曾经错过"的散文由 12 处改动各配一具变异钉住（账见〈`phases.py` 的 docstring 写了七八句"这里曾经错过"，其中六句当时没有读者：`#73`〉），反重复回灌那条链 12 具变异见〈反重复回灌的四个名额全花在同一句话上〉。
- ⛔ M3★ 预注册那片还没跑：plan §十 要的是"一夜加一天发言、在两种前缀长度各跑 5 次"，而真端点上那三局是整局（3/3/4 天），形状不对、样本也不是那 10 次。现在的 `PASS` 意思是"这五条量得出且没有塌缩"，不是"已按预注册口径通过"；~5k 那一档在当前几何下拧不出来。
- ⛔ 天花板该抬到哪里还没量过：六成九的真回答被自家 `max_tokens` 切掉，而 `latency_p95_s` 12.23 对着 `<20.0` 只剩 7.8 秒；173 次真调用里两个解释变量不同步，外推不出来，要一次只换上限的专门探针（`#112`）。canary 延迟比在负载下把自己判成 `INVALID_DRIFT` 那一格是已登记的负结果（`#141`）。
- ⛔ plan §5 那笔前缀缓存的经济性在这台端点上没有可证的读法：三局真桌 173 次调用的 `usage` 里没有 `cached_tokens` 这个键（不是 0），读侧因此只能给 `null`；"为什么"要等 M0 重跑（`#96`），而 M0 那一跑等的是从已 export key 的终端重启 CLI（`#5`、`#10`）。
- ⛔ 对比链的结论路径一次真数据都没走过：`compare` 的 McNemar 与 cluster bootstrap 至今只在替身桌上走过（替身桌按设计必然被拒），真桌那三局是单局、不是一批两臂；`data/` 整目录 gitignored，批次每次都得自己重生成。
- ⛔ 一个人坐进命令行那一桌了，但那桌还是替身桌：`--human 3` 的名册、落盘与三种拒绝都有用例，`actor_kinds` 只能落成 `['human','mock']`；剩下的是 `['human','llm']` 那张混合桌，它需要端点上有活。
